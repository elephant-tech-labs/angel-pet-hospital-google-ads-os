# Google Business Profile Operating System

This folder tracks Google Business Profile (GBP) strategy, audit findings, approved updates, and ongoing local SEO / conversion work for Angel Pet Hospital.

## Purpose

GBP is a major local discovery and conversion channel for Angel Pet Hospital. This module exists to manage it with the same discipline as Google Ads:

- Profile accuracy
- Category and service strategy
- Phone, hours, and URL consistency
- Review generation and response quality
- Photos and media freshness
- Posts / offers / updates
- Local competitor positioning
- Performance trends
- Change logs and client reporting

## Important privacy note

This repository is public. Do not upload raw Google Business Profile admin screenshots, private performance exports, or customer-identifying data here.

Store only cleaned summaries, action plans, and change records.

## Operating rule

No major GBP field should be changed without documenting:

1. Current state
2. Recommended change
3. Reason
4. Approval
5. Date changed
6. Result to monitor

High-risk fields:
- Business name
- Primary category
- Address
- Phone number
- Hours
- Website URL
- Appointment URL
- Services that imply 24/7, emergency, home/mobile, exotics, or advanced surgery
